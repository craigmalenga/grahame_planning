## 5. ENVELOPE CHECK
- **GF width:** Hand-drawn carries the surveyor's **4.34 m** directly (written on basement sheet as the controlling box width). The GF terrace bays 3.25 + 2.5 ≈ 5.75 cover the *terrace* span (over the lightwell, wider than the heated box) not the 4.34 internal — so the 4.34 is for the masonry box, terrace overhangs. **Consistent.**
- **GF length:** room runs (610 cm + 4.5 m living + terrace 2.95 m + vault/toilet strip) sum to ~13.5–13.8 m → **matches 13.77 m** within sketch tolerance. **OK.**
- **Basement width:** `570 cm` matches surveyor **5.70 m**. **OK.**
- **Basement length:** `670 cm` main run + wet-room/stair + patio/vault zones build toward **19.06 m**; not every segment is dimensioned, but no segment contradicts 19.06. **Plausible, OK.**

## 6. CONTRADICTIONS / FLAGS
- **`570` placed on the basement LENGTH axis but equals the WIDTH (5.70).** The hand-drawn "570" sits on a vertical line that, by orientation, reads as a *length*, yet it equals the surveyor's *width* (5.70). Likely the sketcher rotated/mislabelled the axis, OR the lower basement room genuinely is 5.70 long. **Needs confirmation.**
- **`4.34` on the basement sheet** = GF width, not a true basement dimension (basement is 5.70 wide). It is a borrowed anchor, not a measured basement value — do not treat 4.34 as basement width.
- **Terrace bays 3.25 + 2.5 (+cupboard bay) > 4.34** internal width — only reconciles if the terrace cantilevers/extends over the lightwell beyond the masonry box. Worth verifying the terrace does not over-run the boundary.
- **"4.8 m MAX" vs "610 cm"** on the same GF band: two different numbers (4.8 vs 6.1) for adjacent segments of one run — confirm these are sequential segments, not a single span (4.8 + clear-opening note).
- Spiral staircase (GF) vs open staircase (basement) — confirm these are the **same** stair seen on two levels or **two separate** new stairs.
